Indicação de combustão

Pressão no cilindro e análise de combustão, como num sistema de indicação de célula de teste

Páginas deste tópico: Visão geral · IndiCom virtual · Protocolo UDP · Log de indicação

O simulador oferece a indicação de duas formas independentes, que podem ser usadas juntas:

FormaVariávelO que entregaPara quê
Fluxo UDPENGINE_SIM_INDI_UDP Sinais brutos: ângulo do encoder e pressão de cada cilindro, a cada passo da simulação IndiCom virtual ou outra ferramenta de análise. Simula o hardware de indicação (sensor piezo + encoder)
Log por cicloENGINE_SIM_INDI_LOG CSV com uma linha por cilindro e ciclo: Pmax, IMEP, CA10/50/90, VE, massa de ar, eficiência… Calibração do modelo e conferência: inclui grandezas que um banco real não mede (massa aprisionada, combustível queimado)

Fluxo UDP + IndiCom

O simulador faz o papel do hardware: um sensor de pressão em cada cilindro e um encoder de ângulo. Toda a análise (volume, IMEP, liberação de calor, CA10/50/90…) é feita pela ferramenta que recebe, a partir da geometria do motor informada pelo operador — como num banco real.

  1. Configure o destino e, se quiser, as imperfeições do sensor: 
    set ENGINE_SIM_INDI_UDP=127.0.0.1:5005
set ENGINE_SIM_INDI_OFFSET_BAR=0.5
set ENGINE_SIM_INDI_NOISE_BAR=0.05
  2. Abra o simulador (mensagem INDI: streaming cylinder pressure to ...) e o IndiCom virtual, ou use tools\indicom\iniciar_com_simulador.bat.

Imperfeições do sensor

VariávelEfeitoComo tratar
ENGINE_SIM_INDI_OFFSET_BAR Cada sensor recebe um offset fixo aleatório em ±valor [bar] (sensores piezo só medem variação de pressão) Pegging termodinâmico no IndiCom
ENGINE_SIM_INDI_NOISE_BARRuído gaussiano, desvio padrão [bar]Média de ciclos

As imperfeições só afetam o fluxo UDP. O log por ciclo usa a pressão exata da simulação.

Dica: o tools\indicom\selftest.py confere o fluxo sem a interface: python selftest.py 8 escuta por 8 s e imprime as médias por cilindro, para comparar com o log por ciclo.
