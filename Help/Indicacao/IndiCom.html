Instalação (uma vez)

cd tools\indicom
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

Executar

Dê dois cliques em iniciar_com_simulador.bat: ele define ENGINE_SIM_INDI_UDP=127.0.0.1:5005, abre o simulador (build\Release\engine-sim-app.exe) e o IndiCom. Ou, manualmente:

set ENGINE_SIM_INDI_UDP=127.0.0.1:5005
cd build && Release\engine-sim-app.exe
tools\indicom\.venv\Scripts\python tools\indicom\indicom.py

ExibiçãoModo das curvas (ver abaixo)

Num banco real, a geometria vem dos desenhos do motor e o PMS de um sensor de PMS. Aqui o botão Carregar do simulador preenche tudo a partir do pacote de informações do simulador.

Atenção: a geometria importa como num banco real: 1° de erro no PMS muda o IMEP em alguns %, e uma taxa de compressão errada distorce a liberação de calor.

Ângulos em graus depois do PMS de combustão (negativo = antes). A tabela mostra a média dos últimos N ciclos, uma linha por cilindro e a linha "Média".

Modos de exibição

Como num sistema real, as curvas mostram por padrão o ciclo médio: a média das últimas N curvas de pressão (numa grade comum de 0,25°), com a própria liberação de calor e MFB.

ModoMostra
Ciclo médioSó o ciclo médio
Ciclo médio + envelope mín/máxCiclo médio e a faixa mín / máx dos N ciclos (padrão)
Ciclo médio + ciclos sobrepostosCiclo médio e os últimos 20 ciclos em linhas finas
Último cicloO ciclo mais recente (muda a cada ciclo)
Dica: o CA50 do ciclo médio não é a média dos CA50 dos ciclos mostrada na tabela: a média das pressões suaviza a combustão.
