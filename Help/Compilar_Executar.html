Compilar e executar

Dependências, opções do CMake, escolha do motor e primeira execução

Dependências

O CMake precisa encontrar as bibliotecas abaixo (elas devem estar no PATH):

DependênciaUso
SDL2 e SDL2_imageJanela, entrada e imagens
Boost (com os componentes opcionais)Interpretador dos scripts .mr (Piranha)
Flex e BisonGerador do parser dos scripts .mr
Kvaser CANlib SDKSó com CAN_ENABLED=ON. Instalado por padrão em C:\Program Files (x86)\Kvaser\Canlib

O repositório usa submódulos. Clone com:

git clone --recurse-submodules <url do repositório>

Opções do CMake

OpçãoPadrãoFunção
CAN_ENABLEDOFF Liga o controle do dinamômetro via CAN (protocolo AVL EMCON, Kvaser CANlib). Sem esta opção o simulador compila e roda, mas não abre o barramento.
CANLIB_DIRC:/Program Files (x86)/Kvaser/Canlib Pasta do SDK CANlib. O build falha com mensagem clara se canlib.h ou canlib32.lib não forem encontrados.
PIRANHA_ENABLEDONLeitura dos scripts .mr. Mantenha ligado.
DISCORD_ENABLEDONDiscord Rich Presence (herdado do engine-sim). Pode ser desligado.
DTVOFFGravação de vídeo (tecla Insert).

Compilar

  1. Na raiz do projeto: 
    mkdir build
cd build
cmake .. -DCAN_ENABLED=ON
cmake --build . --config Release
  2. O CMake gera uma solução do Visual Studio em build\. Também é possível abrir a solução e executar o projeto engine-sim-app.
  3. Se aparecer erro de DLL ausente ao executar, copie as DLLs que faltam (SDL2, CANlib…) para a pasta do .exe.
AlvoO que é
engine-sim-appO simulador (executável com janela)
engine-simBiblioteca da simulação física
engine-sim-ecuBiblioteca da ECU virtual, sem dependência da simulação (pasta ecu\)
engine-sim-testTestes (Google Test): sistema de gás, funções, sintetizador e ECU

Pastas usadas pelo executável

O simulador procura o arquivo delta.conf ao lado do .exe. Ele tem duas linhas: a pasta do motor gráfico (delta-studio) e a pasta assets, relativas ao executável. Sem o arquivo, usa ../assets.

CaminhoConteúdo
assets\main.mrScript principal: escolhe o motor e as unidades da tela
assets\engines\Scripts de motor (.mr)
assets\calibration\calibration.dcmCalibração ativa da ECU virtual (recarregada ao salvar)
assets\calibration\datasets\Uma calibração por motor (cfr.dcm, gm_ls.dcm…)
es\Biblioteca de nós dos scripts (objetos, peças, sons)

Escolher o motor

O motor carregado é o importado em assets\main.mr:

import "engine_sim.mr"
import "themes/default.mr"
import "engines/cfr/cfr_f1.mr"

use_default_theme(
    torque_units: "Nm",
    power_units: "kW",
    pressure_units: "kPa",
    speed_units: "kph"
)
main()

Troque a linha import "engines/..." e pressione Enter no simulador para recarregar o script sem fechar o programa.

Atenção: a calibração da ECU é por motor. Ao trocar o motor, copie o dataset dele (assets\calibration\datasets\<motor>.dcm) sobre calibration.dcm. Veja Arquivo DCM.

Executar

  1. Defina as variáveis de ambiente das funções que vai usar (CAN, ECU, indicação) no mesmo prompt. O CAN abre sozinho quando o executável foi compilado com CAN_ENABLED=ON; as variáveis só mudam canal, taxa e comportamento.
  2. Rode build\Release\engine-sim-app.exe.
  3. Confira a primeira mensagem no painel de informações: ela informa o estado do CAN, da ECU e da indicação. Veja Mensagens do sistema.
set ENGINE_SIM_CAN_CHANNEL=0
set ENGINE_SIM_INDI_UDP=127.0.0.1:5005
cd build
Release\engine-sim-app.exe
Complete: atalho ou script .bat padrão do laboratório para abrir o simulador já configurado, e a pasta de instalação do executável no PC do banco.
