Parâmetros de combustão

Entradas de engine(), fuel() e intake() adicionadas ou relevantes neste fork

Todas as entradas abaixo são opcionais. Os padrões reproduzem o engine-sim original. A física de cada modelo está em Modelagem física.

engine(...)

EntradaPadrãoSignificado
turbulence_ratio0.5 Intensidade de turbulência no cilindro / velocidade média do pistão. Principal ajuste da velocidade de queima. Maior para cabeçotes com swirl ou tumble forte
flame_model0 0 = original (chama cilíndrica, velocidade calculada só na centelha). 1 = velocidade da chama atualizada a cada passo pelo estado do gás não queimado, riqueza e gás residual. 2 = como 1, com chama esférica, entranhamento e queima (recomendado). Ver Modelos de chama
spark_plug_offset0.0 Modelo de chama 2: posição radial da vela / raio do cilindro (0 = vela central, ~0.8 = vela lateral)
cycle_variation0.0 Modelo de chama 2: desvio padrão (fração) da turbulência vista pelo núcleo da chama em cada ciclo. Define a variação ciclo a ciclo (COV do IMEP)
gas_model0 0 = original (γ = 1,4 constante). 1 = calor específico variável com temperatura e composição, química de mistura rica e não uniformidade da mistura (recomendado). Ver Modelo de gás
mixture_nonuniformity0.1 Modelo de gás 1: desvio padrão da riqueza local / média. ~0,1 para carburador ou injeção no pórtico
wall_heat_transfer0.0 Multiplicador do coeficiente de Hohenberg. 0 = coeficiente constante original (100 W/m²K, quase adiabático). Com o modelo de gás 1 use a correlação publicada, 1.0. Ver Transferência de calor
wall_temperature(90 + 273.15) * units.K Temperatura média das superfícies da câmara (cabeçote, camisa, topo do pistão, válvulas)

fuel(...)

Já existiam, mas os padrões são para um motor de rua "áspero" e normalmente precisam mudar para um motor realista:

EntradaPadrãoSignificado
energy_density48.1 kJ/g Poder calorífico inferior. Gasolina / iso-octano ≈ 43 a 44,3 kJ/g, diesel ≈ 42,8, etanol ≈ 26,8
max_burning_efficiency0.8Fração da carga que pode queimar. Use 1.0
burning_efficiency_randomness0.5 Perda aleatória, ciclo a ciclo, da fração queimada. 0,5 dá COV de falha de combustão; 0,05 é um motor funcionando bem
max_turbulence_effect2.0 Turbulência [m/s] acima da qual a carga queima por completo. Abaixo, parte do combustível não queima (e a aleatoriedade acima se aplica). Deixe abaixo da turbulência do motor nas rotações normais
latent_heat0 Calor de vaporização que o combustível injetado pela ECU retira da carga [J/kg]. Iso-octano 308 kJ/kg, gasolina ~350 kJ/kg; use cerca da metade para carburador ou injeção no pórtico (parte evapora nas paredes). Aumenta em alguns % o ar aprisionado em misturas ricas
Dica: com o modelo de chama 2, use cycle_variation para a variação ciclo a ciclo e mantenha burning_efficiency_randomness baixo (ele só remove combustível ao acaso).

intake(...)

EntradaPadrãoSignificado
air_temperature(25 + 273.15) * units.K Temperatura do ar aspirado (ar condicionado da célula)
Atenção: temperaturas são absolutas. Use só units.K e escreva °C como (t + 273.15) * units.K.

Bloco de combustão (modelo)

Ponto de partida com os valores calibrados do CFR. Ajuste conforme Calibrar contra dados reais.

engine engine(
    ...
    fuel: fuel(
        name: "...",
        energy_density: 44.0 * units.kJ / units.g,
        max_burning_efficiency: 1.0,
        burning_efficiency_randomness: 0.05,
        max_turbulence_effect: 1.2,
        latent_heat: 150 * units.kJ / units.kg
    ),
    turbulence_ratio: 0.95,
    flame_model: 2,
    spark_plug_offset: 0.5,
    cycle_variation: 0.2,
    gas_model: 1,
    mixture_nonuniformity: 0.1,
    wall_heat_transfer: 1.0,
    wall_temperature: (150.0 + 273.15) * units.K,
    simulation_frequency: 20000
)
...
intake intake(
    ...
    air_temperature: (25.0 + 273.15) * units.K
)
Atenção: o turbulence_ratio precisa ser reajustado ao trocar de modelo de chama (CFR: modelo 0 → 1,0; modelo 1 → 0,6; modelo 2 → 0,9; modelo 2 com gás 1 → 0,95).
