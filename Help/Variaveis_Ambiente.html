Variáveis de ambiente

Todas as variáveis lidas pelo simulador na partida

As funções da célula de teste virtual são configuradas por variáveis de ambiente. Elas são lidas uma vez, na partida: defina-as no mesmo prompt (ou no .bat) antes de abrir o engine-sim-app.exe. Para mudar um valor, feche e abra o simulador de novo.

set ENGINE_SIM_ECU_LOG=C:\temp\ecu.csv
set ENGINE_SIM_INDI_UDP=127.0.0.1:5005
Release\engine-sim-app.exe

CAN / dinamômetro

Só têm efeito num executável compilado com CAN_ENABLED=ON. Veja Controle CAN (AVL EMCON).

VariávelPadrãoFunção
ENGINE_SIM_CAN_CHANNEL0Canal Kvaser (0 = primeiro canal da interface)
ENGINE_SIM_CAN_BITRATE500000Taxa em bit/s: 125000, 250000, 500000 ou 1000000
ENGINE_SIM_CAN_PROTOCOL(banco)Protocolo do banco (Dyno_Eddy_Brake.dbc: carga do freio e comando do motor). emcon volta ao AVL EMCON (as variáveis abaixo, até _FILTER_MS, só valem com ele)
ENGINE_SIM_CAN_TIMEOUT_MS500Protocolo do banco: tempo sem ENGINE_Command até voltar para manual (acelerador 0, partida e ignição desligadas)
ENGINE_SIM_CAN_LIFESIGNAL_TIMEOUT_MS0 (desligado) Tempo máximo sem mudança do LifesignalFeedback do HOST em modo remoto. Ao estourar, o simulador volta para Manual com falha. O DBC especifica 100 ms.
ENGINE_SIM_DYNO_SPEED_RAMP_RPM_S1000Rampa da demanda de rotação [rpm/s] (0 = degrau)
ENGINE_SIM_DYNO_TORQUE_RAMP_NM_S2000Rampa da demanda de torque [Nm/s] (0 = degrau)
ENGINE_SIM_DYNO_TORQUE_NOISE_NM1.0Ruído gaussiano da célula de carga, desvio padrão [Nm] (0 = sem ruído)
ENGINE_SIM_DYNO_TORQUE_FILTER_MS50Constante de tempo do filtro da medição de torque [ms] (0 = sem filtro)
ENGINE_SIM_DYNO_MODEL(freio)Padrão: freio de correntes parasitas do banco, carga (0 a 100 %) pelo CAN. ideal: dinamômetro que trava a rotação e gira o motor (CFR). O freio e as variáveis ENGINE_SIM_DYNO_BRAKE_GAIN, _ROTOR_INERTIA, _CAN_ID, _TORQUE_KP/TI, _SPEED_KP/KI e _LOG estão em Freio de correntes parasitas

ECU virtual

Veja ECU virtual.

VariávelExemploFunção
ENGINE_SIM_ECU_LOGC:\temp\ecu.csv Datalog a 20 Hz com todas as medições da ECU, mais λ real do cilindro, AFR, pedal e torque do dinamômetro. Veja Medições e datalog.

Execução sem operador

Para rodadas por script (ensaios automáticos, comparação de resultados), sem ninguém no teclado. As teclas continuam funcionando por cima destes valores.

VariávelExemploFunção
ENGINE_SIM_AUTOSTART3 Liga a ignição e aciona o motor de partida por este tempo [s] (0 = só a ignição).
ENGINE_SIM_DYNO_HOLD600 Liga o dinamômetro mantendo esta rotação [rpm]. Para motorizar o CFR até a rotação (sem partida) use também ENGINE_SIM_DYNO_MODEL=ideal; com o freio é só o alvo do controlador interno.
ENGINE_SIM_THROTTLE1.0 Borboleta com nenhuma tecla de acelerador pressionada (0 a 1).
set ENGINE_SIM_AUTOSTART=0
set ENGINE_SIM_DYNO_MODEL=ideal
set ENGINE_SIM_DYNO_HOLD=600
set ENGINE_SIM_THROTTLE=1.0
Release\engine-sim-app.exe

Indicação de combustão

Veja Indicação de combustão.

VariávelExemploFunção
ENGINE_SIM_INDI_LOGC:\temp\indi.csv Log com uma linha por cilindro e ciclo: Pmax, IMEP, CA10/50/90, VE, massa de ar… Veja Log de indicação.
ENGINE_SIM_INDI_UDP127.0.0.1:5005 Destino (IPv4 host:porta) do fluxo de pressão no cilindro + ângulo do encoder, usado pelo IndiCom virtual.
ENGINE_SIM_INDI_NOISE_BAR0.05 Ruído gaussiano do sensor de pressão, desvio padrão [bar]. Padrão 0.
ENGINE_SIM_INDI_OFFSET_BAR0.5 Cada sensor recebe um offset fixo aleatório dentro de ±valor [bar], como um piezo sem referência. O IndiCom remove com o pegging termodinâmico. Padrão 0.
Dica: o tools\indicom\iniciar_com_simulador.bat já define ENGINE_SIM_INDI_UDP e abre o simulador e o IndiCom juntos. Use-o como exemplo para um .bat do banco.
Atenção: um caminho de log que não pode ser criado (pasta inexistente, arquivo aberto no Excel) não impede o simulador de abrir. Para o log de indicação aparece a mensagem INDI: cannot write ... no painel de informações; para o datalog da ECU não aparece nada. Confira se o arquivo foi criado.
