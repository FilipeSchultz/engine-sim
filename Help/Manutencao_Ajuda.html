Como editar a ajuda

Estrutura dos arquivos, criação de páginas e como abrir a ajuda

Estrutura da pasta

Help\
  index.html              moldura (árvore + pesquisa + conteúdo)
  estilo.css              visual das páginas de conteúdo
  _Modelo.html            modelo para criar páginas novas
  Inicio.html             página inicial
  Compilar_Executar.html  ...demais páginas da raiz
  Operacao\               teclado, telas, dinamômetro, mensagens
  Motores\                scripts de motor e calibração do modelo
  Modelagem\              modelos físicos
  ECU\                    ECU virtual
    _Modelo_Funcao.html   modelo para páginas de função da ECU
  Comunicacao\            CAN (AVL EMCON) e XCP
  Indicacao\              indicação de combustão e IndiCom
  img\                    prints de tela (opcional)
  _sys\
    toc.js                ÁRVORE DE CONTEÚDO (editar ao criar páginas)
    pagina.js             script das páginas (não editar)
    frame.js, frame.css   moldura (não editar)
    img\                  logo, capa e favicon da marca (SVG)

Criar uma página nova

  1. Copie _Modelo.html e renomeie, sem acento e sem espaço (ex.: Roteiro_Ensaio.html).
  2. Edite o <title>, o <h1> e o conteúdo. Mantenha a linha <script src="_sys/pagina.js"> no cabeçalho.
  3. Abra _sys\toc.js e adicione a página na árvore: 
    { titulo: 'Roteiro de ensaio', pagina: 'Roteiro_Ensaio.html' }
  4. Atualize a página no navegador (F5). A pesquisa passa a incluir a página automaticamente.

Subpastas e subtópicos

Páginas podem ficar em subpastas, como ECU\. Numa subpasta:

  • Os caminhos no cabeçalho começam com ../: ../estilo.css, ../_sys/pagina.js e imagens em ../img/. O modelo ECU\_Modelo_Funcao.html já vem assim.
  • No toc.js, o caminho inclui a pasta, com barra normal: pagina: 'ECU/Funcoes.html'.
  • Links entre páginas da mesma pasta usam só o nome (Funcoes.html). Para outra pasta, use ../ (../Operacao/Dinamometro.html).

Para dividir um tópico em várias páginas, faça um item com pagina e filhos. Clicar no nome abre a visão geral e mostra as subpáginas:

{
  titulo: 'ECU virtual',
  pagina: 'ECU/ECU.html',
  filhos: [
    { titulo: 'Funções',    pagina: 'ECU/Funcoes.html' },
    { titulo: 'Parâmetros', pagina: 'ECU/Parametros.html' }
  ]
}

Atenção: a pesquisa só enxerga páginas que estão na árvore (toc.js). Uma página fora da árvore abre normalmente, mas não aparece nos resultados.

Abrir a ajuda

Abra Help\index.html no Chrome ou no Edge (dois cliques, ou um atalho na área de trabalho). Para abrir direto numa página, aponte para o arquivo dela (ex.: Help\ECU\Parametros.html): a página detecta que foi aberta sozinha e se recarrega dentro da moldura, já com a árvore e a pesquisa.

Um link também pode usar o parâmetro p: index.html?p=ECU/Parametros.html.

Ainda não há tecla de ajuda no simulador (F1 a F3 já giram o desenho do motor). Se for criada, use por exemplo ShellExecuteA(nullptr, "open", caminho_da_pagina, nullptr, nullptr, SW_SHOWNORMAL) com o caminho absoluto de Help\index.html ou da página da tela atual, e documente aqui a tecla escolhida.

Limitações conhecidas

  • A moldura foi feita para Chrome e Edge.
  • Na primeira vez que a aba Pesquisar é usada, as páginas são lidas em segundo plano (leva cerca de um segundo por dezena de páginas).
